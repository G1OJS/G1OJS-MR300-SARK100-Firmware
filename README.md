# G1OJS Updates to MR300 / SARK100 Firmware
## Intro
This [Github repository](https://github.com/G1OJS/G1OJS-MR300-SARK100-Firmware) contains the results of a lot of work I've done investigating the [MR300 Antenna Analyser](http://www.lxqqfy.com/e/product.php?id=MR300)'s firmware (SARK100 firmware V13), mainly for my own education & fun. 

I took a very deep dive into the source of noise on some meaasurements, and the maths explaining why measuring impedance is tricky (especially near match or even low reactance mismatches). See the explanations on the website below.

## Features added
Things I added include:
* Power meter (both for output power used during reflectometry and as a passive power meter)
* Cable length measurement
* Morse code status beeps
* Fast auto-step scanning routine
* Internal frequency sweep smoothing
